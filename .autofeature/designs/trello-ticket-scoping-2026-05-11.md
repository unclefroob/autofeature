## Request

Add a pre-step to autofeature that detects a Trello card URL in the feature request, fetches the card via the Trello API, generates a technical scope comment, posts it back to the card, and uses the card content as the canonical feature request for the rest of the pipeline.

## Decisions

| Decision | Choice | Reason |
|----------|--------|--------|
| Input method | URL detection (`trello.com/c/`) | Zero syntax overhead — paste a URL, autofeature handles it |
| Credentials | Trello MCP server (`@delorenj/mcp-server-trello`) — inherits `TRELLO_API_KEY` + `TRELLO_TOKEN` from shell env | Credentials never appear in any config file or skill file |
| Missing MCP behaviour | Check if `mcp__trello__*` tools are available; if not, emit setup instructions and fall back to raw prompt | Graceful degradation |
| Step placement | Between Step 0 (Resume) and Step 1 (Mode + Input) as **Step 0.5** | Card content needs to be available before mode selection uses the feature request |
| Checkpoint behaviour | Show scope comment preview + 4 options before posting | User Sovereignty — never post to Trello without approval |

---

## Trello MCP Tools Used

The skill calls MCP tools directly — no credentials, no curl:

```
mcp__trello__get_card_details    → fetch card name, desc, labels, due
mcp__trello__get_card_checklists → fetch acceptance criteria
mcp__trello__add_comment_to_card → post technical scope comment
```

**MCP setup (one-time, user-side):**
```bash
# ~/.zshrc
export TRELLO_API_KEY=your-key   # from https://trello.com/app-key
export TRELLO_TOKEN=your-token
```
MCP server registered at user scope via `claude mcp add -s user trello -- npx -y @delorenj/mcp-server-trello`. ✓

## Feature Request Extraction from Card

| Card field | Used as |
|-----------|---------|
| `name` | Feature title |
| `desc` | Feature description / context |
| Checklists | Acceptance criteria (appended to description as bullet list) |
| `labels` | Scope hints (e.g. "bug" → fix mode, "enhancement" → feature mode) |
| `due` | Noted in brief if present |

The extracted feature request replaces the user's raw prompt for all downstream steps (interrogation, scope gate, plan, etc.).
